# Эталонные посты

Сюда кладутся посты, написанные автором вручную. Модель получает их как образец голоса,
и именно от них зависит, будет ли канал звучать как автор, а не как ChatGPT.

Структура: по папке на рубрику, каждый пост — отдельный файл `.md` или `.html`
с текстом в том виде, в каком он должен выглядеть в Telegram (HTML-разметка).

    prompts/examples/concept/01-kvantizaciya.md
    prompts/examples/history/01-perceptron.md

Для квиза — JSON в том же формате, что и ответ модели:

    prompts/examples/quiz/01.json

Файлов нет — модель пишет только по стайлгайду. Этого хватит, чтобы проверить механику,
но не чтобы запускать канал: минимум — по одному посту на рубрику, лучше 2–3.
