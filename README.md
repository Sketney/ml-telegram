# ML-telegram

AI-редакция для Telegram-канала про ML/AI: бот готовит черновики по рубрикам, автор одобряет
или правит их в личке, одобренное выходит в канал по расписанию. Без решения автора в канал
не уходит ничего.

Сейчас готов **этап 1**: бот модерации, планировщик и три вечнозелёные рубрики —
«Понятие недели», «История ML», «Квиз».

## Быстрый старт

1. Создай канал и бота (@BotFather), добавь бота админом канала с правом публикации.
2. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN`, `CHANNEL_ID`, `ADMIN_ID`, `POSTGRES_PASSWORD`.
3. Запусти:

   ```bash
   docker compose up -d --build
   docker compose logs -f bot
   ```

4. Напиши боту `/help`.

С `LLM_PROVIDER=fake` ключ не нужен: бот отдаёт тексты-заглушки, и на них можно проверить
кнопки, расписание и публикацию (в тестовый канал). Для настоящих черновиков поставь
`LLM_PROVIDER=anthropic` или `openai` и задай `LLM_API_KEY`. На ключе обязательно поставь лимит трат.

## Как это работает

```
бэклог тем → генерация (стайлгайд + шаблон рубрики + эталонные посты)
           → валидатор (разметка Telegram, длина, заглушки, стоп-фразы)
           → карточка автору в личку → кнопки → очередь → канал по расписанию
```

- Каждый день в `prepare_at` бот проверяет рубрики из расписания и, если черновика в работе нет,
  готовит новый и присылает на модерацию.
- В момент слота публикуется самый старый одобренный черновик рубрики. Одобренного нет — слот
  пропускается, бот пишет об этом.
- Черновик с ошибками (⛔️ в карточке) опубликовать нельзя: сломанная разметка, превышение лимитов
  Telegram, незаполненная заглушка вида `{Мой опыт}`.

### Кнопки под черновиком

| Кнопка | Что делает |
| --- | --- |
| ✅ Сейчас | Публикует в канал сразу |
| 🕒 В расписание | Ставит в очередь на ближайший слот рубрики |
| ✏️ Править | Ждёт твой текст одним сообщением; форматирование Telegram сохраняется (только посты) |
| 🔄 Заново | Новая версия по той же теме |
| 💬 С комментарием | Новая версия с учётом замечания: «короче», «добавь пример» |
| ⏸ Отложить | Убирает из очереди, черновик остаётся в `/queue` |
| ❌ Отклонить | В архив, тема больше не предлагается |

### Команды

| Команда | Что делает |
| --- | --- |
| `/gen рубрика [тема]` | Черновик по следующей теме из бэклога или на свою тему |
| `/add рубрика тема` | Добавить тему в бэклог |
| `/topics` | Сколько новых тем осталось по рубрикам |
| `/queue` | Черновики в работе |
| `/show номер` | Показать черновик ещё раз |
| `/cancel` | Отменить ввод текста или комментария |

Ключи рубрик: `concept`, `history`, `quiz`.

## Что настраивается без кода

| Файл | Что в нём |
| --- | --- |
| `prompts/styleguide.md` | Голос канала. Уходит в промпт целиком — правь под себя |
| `prompts/rubrics/*.md` | Шаблон и требования каждой рубрики |
| `prompts/examples/<рубрика>/` | Твои эталонные посты: главный рычаг качества, см. README там |
| `data/backlog.yaml` | Бэклог тем; новые строки подхватываются при запуске |
| `data/schedule.yaml` | Дни и время слотов, время подготовки черновиков |
| `data/rubrics.yaml` | Названия, хештеги, рекомендованная длина |
| `.env` | Токены, фирменный эмодзи, подпись канала, часовой пояс |

`prompts/` и `data/` примонтированы в контейнер: поменял файл → `docker compose restart bot`.

## Разработка

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
pytest
```

Нужен Python 3.10+. Тесты поднимают мок-сервер Telegram Bot API и гоняют настоящий диспетчер
aiogram: команды, кнопки, публикацию и расписание — без сети и токенов.

Без Docker бот запускается так: `python -m app.main` (по умолчанию база — SQLite-файл рядом;
для этого нужен пакет `aiosqlite` из dev-зависимостей).

## Структура

```
app/
  main.py         точка входа: конфиг, база, бот, планировщик
  config.py       настройки из .env
  models.py       Topic, Draft
  generator.py    бэклог и генерация черновиков
  validator.py    проверки разметки и лимитов Telegram
  moderation.py   действия над черновиком: одобрить, опубликовать, отклонить…
  publisher.py    отправка поста или квиза в чат
  scheduler.py    расписание: подготовка и публикация
  llm.py          Anthropic / OpenAI / fake
  bot/            хендлеры и карточка черновика
prompts/          стайлгайд, шаблоны рубрик, эталонные посты
data/             бэклог, расписание, рубрики
tests/            тесты и мок Telegram
```
